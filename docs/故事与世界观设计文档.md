# 一、一句话概念

> **你是被贬下凡的厨子，守一口凡锅、一坛老卤，一路把一只又毒舌又贪吃的女饕餮喂大。**
>
> **相传熬过味劫便能渡劫飞升——但从来没有哪个厨子飞升过。每一局的终局，都是被吃饱的饕餮连同这口锅一并吞下，再投胎重来。**
>
> **喂得好，她吞你之前赏一句"尚可"；喂不好，她连评价都懒得给。**

---

# 二、世界观

- 世间有**七味**：酸、甜、苦、辣、鲜、咸、麻。天庭以"味"论高下。
- 每隔一段岁月，天地之味失衡，降下**味劫**。平息味劫的唯一办法：**用至味喂饱镇守的凶兽——饕餮**。
- 饕餮被天庭封印成**幼体**，只认人间的味道。你喂得越多，她长得越快。
- **你**：一个被贬下凡的厨子（默认名"晏无咎"，可改）。一口能煮万物的**凡锅**、一坛越熬越醇的**老卤**，是你全部的家当。
- **老卤（锅底）**：跨锅累积的"味之本"，是你唯一能带过味劫的资本。
- **轮回**：相传熬过味劫便可渡劫飞升，但从来没有厨子飞升过。每一局的终局，饕餮都会把投喂者连同这口锅一并吞下——**这是天规，不是报复**。厨子投胎重来，味劫如期重演。

> 「渡劫飞升」是流言，也是诱饵；「投胎重来」才是真相。
>
> 本作以"好玩"为先：剧情只负责给玩法一个好由头，不追求复杂的恩怨。

---

# 三、饕餮（唯一的重要角色）

- **女体，会变强、会变美**，随章节进化：

| 章节节点 | 形态 |
|---|---|
| 第 1 章末 | 萝莉（奶凶的小祖宗） |
| 第 2 章末 | 少女（毒舌的盯梢者） |
| 第 3 章末 | 御姐（半醒的味劫） |
| 第 10 锅 | 真身（味道天劫本身） |

- **性格**：毒舌、贪吃、嘴硬心软。你喂得好，她嘴上嫌弃、身体很诚实。
- **关系**：**投喂即养成**——她越长越开，全看你喂得怎么样。
- **章末试吃**：每章末（第 3 / 6 / 9 锅的最后一碗），她会中途现身试吃这一锅。
  - 满意：放你继续熬。
  - 嫌弃：当场被吞，本局到此为止，投胎重来。
- **终局**：无论结果如何，最终锅的结局都是**她把你连同这口锅一并吞下**——你永远回到起点。
  - 满意：一句"尚可"（她的最高评价），你带着这句评价重新投胎。
  - 嫌弃：抬爪吞锅，冷冷一句"重来"；但偶尔，她也会别别扭扭地补一句鼓励。
  - 区别只在她吃你之前，**满不满意**。
- **赏赐**：满意时，她会在吃你之前吐出一撮**仙丹粉末**——她吃剩的余味。这是你唯一能带进下一次轮回的东西。
- 乳名"**阿餮**"，全天下只有主角敢这么叫。（她嘴上骂，心里受用。）

# 四、出场角色（轻量）

- **灶下**：锅底里的一团青火，锅的"魂"。聒噪、护锅，负责当**引导者与解说**（新手向导）。
- **监味星君**：天庭派来监督你的小官，心软、爱念叨。负责发放"**仙庭赏赐**"（解锁新食材），并在每章之交为你指点接下来的**餐饮风潮**（路线）。

> 其余角色（游魂食客、判官等）留作后续按需补充，不急着堆人设。

---

# 五、名词表（只留必要的）

- **味劫**：天地之味周期性失衡降下的劫。必须以人间至味喂饕餮才能平息；对厨子而言，是修行的关口，也是被吞入轮回的宿命。
- **老卤**：凡间灶火长年炼出的"味之本"，跨锅累积，即游戏里的"锅底"。
- **仙庭赏赐**：天庭按功德发放的奖赏，用来解锁更多**已知食材**。
- **七荤八素**：味劫试炼之名。七味俱足、火候兼备者方过门槛。
- **轮回**：厨子的宿命。每局终局被饕餮吞下，投胎重来；味劫与修行一并重演。唯一能带过轮回的，是口舌间的一点余味。
- **仙丹粉末**：饕餮吃剩的余味凝成的粉末。满意时她赏你少许，可带入下一次轮回（局内至多保留 1 份）。
- **餐饮风潮**：监味星君指点的"天时"。每章之交择其一，会影响接下来新食材的获取倾向与采买的偏向。

# 六、叙事 ↔ 机制

| 游戏机制 | 叙事解释 |
|---|---|
| 一锅 10 碗、3 章 × 3 锅 | 味劫的试炼节奏 |
| 每章末的"七荤八素门槛"（第 3 / 6 / 9 锅的最后一碗） | 饕餮的中途试吃 |
| 章末试吃不满意 → 本局终止 | 当场被吞，投胎重来 |
| 饕餮逐章变强、四形态 | 投喂即养成 |
| 任何结局 = 本局重开 | 轮回：终局必被吞下 |
| 满意掉落「仙丹粉末」 | 她吃前留下的余味 |
| 「仙丹粉末」可跨局保留 1 份 | 唯一能带过轮回的东西 |
| 每章之交的路线选择（1 保底 + 2 餐饮风潮） | 监味星君指点接下来的风向 |
| 锅底跨锅累积 | 老卤 |
| 局外成长解锁食材 | 仙庭赏赐 |
| 稀有食客 → 伙伴 | 一路结交的帮手 |
| 7 种味道 / 杂与精 | 七味俱足、八功兼备，方过门槛 |

# 七、基调与美术风格

- **基调**：滚烫、喜庆、带点毒舌的幽默；古神威仪里透出烟火气。
- **美术核心**：中国**青铜饕餮纹 · 暗黑奇幻**。
- **配色**：青铜绿 / 氧化铜、暗金、赭石、石青、金箔；点缀炭橙、朱砂红。
- **质感**：厚涂油画 + 敦煌矿物颜料颗粒感，汤汁与火光自发光。
- **参考气质**：商周青铜器、《战神》的雕塑感、《哈迪斯》的发光质感。
