# 《七荤八素》立绘风格规范

> 版本：v2
> 文档状态：已定稿
> 定位：美术真源（**立绘层**）。剧情插图、演出大图、卡面插画、宣发关键视觉统一遵循本文档。
> 关系：游戏内界面与局内玩法层（像素 #069）见《界面风格规范》；叙事见《故事与世界观设计文档》。

# 一、风格定义

- **统一风格**：Spellbook **#191「Modernized Song-Dynasty Light Color · 宋画淡彩现代化」**。
- **视觉特征**：米白留白、细线、青绿赭石、古典安静。
- **游戏整体定位**：**中式 + 搞怪搞笑**。
- **贯穿母题**：**青铜饕餮纹（兽面纹）**。

> ⚠️ 已知张力：#191 的气质是「古典安静」，与饕餮「毒舌贪吃」的性格相反。**风格不动，靠表情与姿态找回幽默感**（见 §4.3）。

---

# 二、立绘模板 v2（三段式）

> **`[人物主体描述]` + `固定约束` + `风格槽`**

## 2.1 固定约束（每张都不变）

- 单一主体
- 竖版立绘、居中
- 留白整洁背景
- 克制配色（见「三、配色」）
- 清晰柔和的光
- **不极繁、无杂乱元素**（不使用 intricate / ornate / busy / cluttered / dense details 一类词）

## 2.2 风格槽（固定）

```
Style name: #191 Modernized Song-Dynasty Light Color — rice-white negative
space, fine delicate lines, celadon green and ochre pigments, classical and quiet.
```

## 2.3 英文模板（可直接复用）

```
a game character standing illustration (vertical key art) of a single figure:
[人物主体描述]. Single subject, clean empty background with generous negative
space, restrained palette of bronze-green, ink-black and dark gold with a touch
of cinnabar, clear soft light, not maximalist, no clutter. Style name: #191
Modernized Song-Dynasty Light Color — rice-white negative space, fine delicate
lines, celadon green and ochre pigments, classical and quiet.
```

# 三、配色

- 底色：**米白 / 宣纸留白**
- 主色：**青绿、赭石、墨黑**
- 点缀：**暗金、朱砂红**（少量）
- 目标：低饱和、克制、清淡雅致。

## 4.2 其他角色

- **灶下**（锅底青火小妖／引导者）：玉绿火苗小妖、贱嘴、两颗火星牙、大眼睛；聒噪护锅，又坏又可爱。非人角色同样套用本文档模板。
- **主角（厨子）**、**食客 / 伙伴**：待补充（沿用同一模板）。

## 4.3 幽默感的找回（v2 新增）

#191 偏「古典安静」，容易把毒舌搞怪的角色画得太雅。因此：

- **风格槽不动**，在主体描述里下功夫：写清「嘟嘴／翻白眼／叼东西／撑腮／嫌弃脸」等具体表情与姿态；
- 允许显式加入 `cheeky`／`grumpy`／`smug`／`sulking` 一类情绪词；
- 表情与肢体动作要服从角色的人格机制，避免回落为统一的标准美型脸。

# 五、生图技术约定

1. **模型**：调用 `generate_image` 时必须**显式指定** `model = "[次]gpt-image-2.5"`（默认会路由到已失效的 dall-e，返回 HTTP 503）。
2. **尺寸**：竖版立绘用 `1024x1536`；`quality = high`；`n = 1`。
3. **文件名**：kebab-case 英文，v2 批次加 `-191` 后缀（如 `taotie-form1-loli-191.png`）。
4. **存放**：`generated-images/角色立绘-191/`。
5. **版本管理**：`generated-images/` 已加入 `.gitignore`，**图片不入版本库**。

# 六、与游戏内美术的关系

| 层 | 用途 | 风格 |
|---|---|---|
| **A 立绘层**（本文档） | 剧情插图、叙事屏大图、卡面插画、宣发关键视觉 | **#191 宋画淡彩** |
| **B 界面 / 局内层** | 全部 UI、局内角色、大锅、食材与道具图标、特效、装饰 | **#069 像素（全像素）** |

- **局内与界面一律像素**：界面内出现的角色也是像素，**不嵌入淡彩立绘**（依据 2026-09 用户确认，`ui-01b` 全像素方案胜出）。
- 两层共用**青铜饕餮纹**母题（像素层用点阵纹样，立绘层用笔意）。
- **叙事屏使用淡彩大图**：章末饕餮验收、开局、结局等叙事屏，使用 #191 淡彩立绘**大图**作为主视觉，叠加在像素界面之上。
